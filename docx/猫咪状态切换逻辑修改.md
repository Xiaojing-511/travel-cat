## 2. 需求对照

### 硬性规则

| 需求 | 实现 |
| --- | --- |
| 旅行时长上限 48 小时 | `TRAVEL_MAX_MS`，出发时强制截断 |
| 「出门了」旁展示已出门分钟 | 首页 `awayText`：`已出门 XX 分钟`（按已过分钟向下取整） |
| 状态切换不随机到当前相同状态 | `pickNextActivity` 从候选池剔除当前 `activity` |

### 日常状态时长

| 状态 | 原实现 | 现实现 |
| --- | --- | --- |
| 睡觉 | 固定 5 分钟 | 随机 5 分钟 ~ 1 小时 |
| 发呆 | 随机 45~120 秒 | 随机 2 分钟 ~ 20 分钟 |
| 在等你 | 随机 30~90 秒 | 随机 10 分钟 ~ 3 小时 |
| 出门前犹豫 `decide` | 12~25 秒后自动出门 | 加回日常轮换，12~25 秒后 **1/3** 出门 |

### 「你回来了」

- 猫咪当前是「在等你」，且玩家是**进入小程序**（冷启动或从后台回来，不是从相册返回）。
- 弹出对话框标题「你回来了」。
- 若粮、水都为 0 且该空碗状态已持续 **大于 3 小时** → 切到「等饭中...」(`hungry`)。
- 否则 → 切到「发呆」(`idle`)。
- 「等饭中...」不再等于「碗空时的发呆文案」：发呆固定显示「发呆中...」，只有 `hungry` 显示「等饭中...」。
- **在线时**日常轮换是睡觉 / 发呆 / 犹豫出门 `decide`（以及符合条件的等饭），不会随机切到「在等你」。`wait` 只在离开后再打开的离线追赶里出现。

### 吃饭 / 喝水

- 睡觉、旅行中不判定；睡醒或回家后补做到期判定。
- 每 2~3 小时判定一次是否喝水，每 5~6 小时判定一次是否吃饭。
- 判定时 **1/3 概率发生、2/3 概率跳过**。
- 粮=0 时不判定为吃饭；水=0 时不判定为喝水。
- 抽中后消耗 **5~10g** 随机（不超过剩余）。
- **没有** 24 小时次数保底。
- 发生时切到短状态：吃饭约 2~5 分钟「吃饭中...」，喝水约 1~3 分钟「喝水中...」。

### 旅行机制

| 项目 | 原实现 | 现实现 |
| --- | --- | --- |
| 触发 | 碗满时抽到 `decide`，到期自动出门 | 日常轮换抽到 `decide`，到期 **1/3** 出门 |
| 24 小时上限 | 出发后先冷却 24 小时，再在接下来的 24 小时内随机判一次；睡觉中判到则错过本轮 | **已删除**；出门改由 `decide` 轮换驱动 |
| 低物资 | 粮或水 < 10g **不能**出门 | 可以出门（低档，出发耗尽剩余粮水） |
| 时长 | 固定 5 分钟 | 按下表按库存分档，且不超过 48 小时 |

物资分档（粮、水都达标才算该档，从高到低匹配）：

| 出发时库存 | 旅行时间 n | 出发消耗 |
| --- | --- | --- |
| 粮、水都 < 10g（低档） | 30 分钟 ~ 6 小时 | 耗尽剩余粮、水 |
| 粮、水都 ≥ 10g（中档） | 1 小时 ~ 12 小时 | n > 6 小时：各扣 10g；否则不扣 |
| 粮、水都 ≥ 20g（高档） | 2 小时 ~ 24 小时 | n > 12 小时：粮 20g、水 10g；6h < n ≤ 12h：各 10g；否则不扣 |

说明：喂食上限 50g，高档（≥20g）可以通过多次点击「喂」达到。

## 3. 关键存档字段（新增）

| 字段 | 含义 |
| --- | --- |
| `createdAt` | 建档时间 |
| `emptySince` | 粮、水都为 0 的起始时间；碗里有东西则为 0 |
| `lastTravelAt` | 上次出发时间 |
| `nextDrinkCheckAt` / `nextEatCheckAt` | 下一次喝水/吃饭判定时间 |

`tick` 会按事件时间追赶：关掉小程序期间的睡觉结束、吃饭喝水、`decide` 出门、旅行归来都会一次性补上。

---

## 4. 未改动的部分

- 喂食：粮或水未到 50g 时可点，每次各 +10g，封顶 50g。
- 明信片抽取、未读角标、相册页逻辑不变。
- 睡觉序列帧、门口背影、背包图（仅「发呆且粮水都 ≥ 10g」）不变。
- 旧存档 `pose` / `activity: decide` 可迁移（`decide` 会保留）。
