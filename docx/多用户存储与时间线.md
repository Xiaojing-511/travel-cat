# 多用户存储与时间线

环境 ID：`cloud1-4grqnt5f5b5d8f20`

## 原则

- openid 只在云函数里从 `wxContext` 读取，游戏只认 `userId`。
- 时间以云函数 `Date.now()` 为准。客户端倒计时用上次 `serverNow` + 单调钟插值。
- 云端不实时推猫，打开或操作时追赶时间线。
- 无网展示缓存，喂食 / 追赶 / 欢迎回家不落地。

## 集合

- `users`：`_id = userId`，`openid` 唯一。
- `players`：`_id = userId`，时间线、库存、`nickname`、`breed`、`breedLocked`、`hasUnreadCard`、`lastCardTemplateId`、`cardCount`、`tutorialDone`、`rev`。
- `cards`：每张明信片一条，`userId` + `collectedAt`。

客户端对三张表都应 `read: false`、`write: false`，只走云函数 `player`。

## 云函数 `player`

`event.action`：`ensureDb` / `login` / `sync` / `feed` / `welcomeHome` / `clearUnread` / `readCard` / `updateProfile` / `completeTutorial` / `hide` / `listCards` / `harvestPlanter`。

阳台三盆各自保存 `leaves`、`nextGrowAt`、`hint`，总叶子在 `leafCount`。生长在 `tick` 里按每盆 10 分钟～4 小时结 10 叶追赶，每盆最多 30 叶；采收走 `harvestPlanter`。没有 `leafStockEpoch` 的旧存档，下次同步时把 `leafCount` 清零一次，花盆上已结的叶子不动。

`tutorialDone` 不是 true 时，服务器时间暂停，打开首页会进入新手引导。`completeTutorial` 把它写成 true，并接上暂停期间顺延后的时间线，不改当前动作。

`updateProfile` 可只传 `nickname` 或只传 `breed`。昵称会去掉前后空格，最长 10 个字，默认「小咪」。品种为 `american`（美短）、`blue-golden`（蓝金渐层），第一次保存后 `breedLocked`，不能再改。

品种登记在 `miniprogram/utils/game.js` 的 `BREEDS`。新增一只猫只加一条：`spriteDir` 放包内姿势图（文件名与美短相同），`cardFolder` 是云存储目录（文件名与 `travel-cards` 相同）。选定后首页姿势图和明信片照片都走这一条，旅行日程、手记和抽卡不变。未选定品种时按美短展示。

部署前执行 `npm run after-edit`（测试 + 打包旅行图 + 把 `game.js` / `trips.js` 拷进云函数）。不要手改 `cloudfunctions/player/utils/game.js`。

## 开发者工具

1. 开通该环境，上传并部署云函数 `player`（先装依赖 `wx-server-sdk`）。
2. 调用一次 `ensureDb`，或在控制台建 `users` / `players` / `cards`。
3. 给 `users.openid` 加唯一索引；`cards` 加 `userId` + `collectedAt` 降序。
4. 三集合权限对客户端关闭。
5. 真机或模拟器登录后冷启动、杀进程再开、改系统时间、无网喂食。
